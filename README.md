# Египет — путешествие сквозь тысячелетия

Русскоязычная интерактивная экспозиция из семи глав. На компьютере прокрутка ведёт камеру через объёмный каменный портал: золотистый свет, переход фокуса и три плана песчаных частиц. На телефоне и при включённом уменьшении движения доступен прямой маршрут чтения. Исторические тексты, изображения и ссылки работают без JavaScript.

Панорама под аркой и пролёт используют одно изображение с одинаковым кадрированием: начало прокрутки больше не подменяет фотографию. Разделы появляются по очереди при прокрутке. В каждой теме заголовок, текст и факты выезжают слева, а фотографии с подписями — справа. Обе стороны движутся одновременно за 1,3 секунды. Движение начинается, когда раздел входит в экран примерно на треть его высоты. Анимации чтения проигрываются один раз и полностью убираются при выключении движения.

## Запуск

Нужны Node.js 22.12+ и npm. В PowerShell из папки проекта:

```powershell
npm.cmd install
npm.cmd run dev
```

Адрес: **http://127.0.0.1:4173/**. Чтобы остановить сервер, нажмите Ctrl+C в его терминале. HTML следует открывать через сервер, а не двойным щелчком по файлу: модули и ресурсы используют локальные URL.

На Windows включено периодическое наблюдение за файлами, чтобы краткие блокировки OneDrive не завершали Vite.

## Сборка и проверки

```powershell
npm.cmd run test
npm.cmd run build
npm.cmd run preview
```

Перед `preview` остановите `dev`: обе команды используют порт 4173. Результат сборки находится в `dist/` и готов для статического хостинга с HTTPS.

Дополнительная браузерная проверка:

```powershell
npm.cmd run check:browser
```

Она использует установленный Chrome по пути `C:/Program Files/Google/Chrome/Application/chrome.exe`, запускает его без окна и проверяет работающий сервер. Отчёт и снимки сохраняются в `.impeccable/review/`. Устанавливать браузер Playwright отдельно для этой проверки не требуется.

Проверка непрерывности отдельно подтверждает видимость сцены до первой прокрутки, общий источник панорамы, отсутствие смешивания фотографий, синхронность движения текста и фото во всех семи темах, завершение анимаций и восстановление содержимого при отключении движения. Снимки этой проверки — `motion-rest.png`, `motion-fallback.png`, `motion-start.png` и `motion-reading.png`.

Проверены размеры 1672, 1440, 1280 и 390 px; семь доступных глав, отсутствие горизонтального переполнения, переходы по главам, возврат камеры, клавиатура, выключение анимации, изменение системной настройки движения, недоступный WebGL, потеря контекста, отказ панорамы и остановка рендера при событии скрытия страницы. Скрытие проверяется внедрением события в тесте. Интервалы кадров headless Chrome не заменяют замер на компьютере посетителя.

Готовая сборка отдельно проверена через `preview` на 1440 и 390 px: шрифты и материалы загружаются, переход к первой главе работает, ошибок страницы и горизонтального переполнения нет. Отчёт — `.impeccable/review/production-report.json`. Независимый просмотр выявил шесть визуальных замечаний; все шесть исправлены и получили вердикт `ship` в `.impeccable/review/verdict-1.md`. Этот вердикт относится к указанным исправлениям.

## Материалы и источники

- `index.html` — весь текст и музейные ссылки; редактировать содержание можно прямо здесь.
- `src/styles.css` — типографика, композиция, адаптация и состояния интерфейса.
- `DESIGN.md` и `.impeccable/design.json` — фактические токены, компоненты и правила дальнейшего оформления.
- `src/experience/` — абсолютная модель камеры, прокрутка, навигация и таблички.
- `src/scene/` — Three.js, объём опор, шейдер глубины, свет и simplex-потоки частиц.
- `public/assets/manifest.json` — пути материалов; `sources.json` — первичные исторические источники.
- `public/assets/objects/` — фотографии Хатшепсут, Осириса, папируса Науни и мастерской Мекетры. The Metropolitan Museum of Art, Open Access, Public Domain. Карточки предметов указаны рядом с изображениями и в источниках.
- `public/assets/fonts/` — локальные Cormorant Garamond и Manrope, лицензии OFL приложены.

Портал и пейзажи созданы с помощью ИИ. Это художественные реконструкции, а не фотографии конкретного храмового комплекса и не точная модель расположения памятников. Подписи есть в экспозиции. Точные промты встроены в PNG; происхождение фотографий записано в JPEG. Исходное задание, референсы и все три макета сохранены.

Фактическое разрешение материалов: портал 1788×880, Гиза 1374×1147, расширенная панорама 1942×809, Нил 1672×941, папирус 1254×1254. Это нативные результаты генератора, не 4K-исходники. Для нового крупного экрана можно заменить файлы более детальными версиями с сохранением прозрачности портала и композиции.

## Производительность и управление

Солнце в навигации выключает или включает анимацию. Настройка запоминается локально. На телефоне сцена не запускается; при системном уменьшении движения длинный пролёт и наклон отключены. При потере WebGL страница возвращается к обычной прокрутке.

Графика загружается отдельными модулями. В активном режиме Lenis и WebGL используют один цикл GSAP. Pixel ratio ограничен 1.5 и снижается при длительных медленных кадрах; число частиц ограничено. 60 FPS — цель для подходящего GPU, не гарантия для всех устройств. Растровый портал и панорама имеют перспективную глубину и объёмные опоры; это сценическая реконструкция, не фотограмметрическая модель храма.

Проект запускается локально. Публичный домен и место размещения пока не выбраны.
